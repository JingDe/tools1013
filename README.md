> 所有工具都归在同一个 GitHub 账号（`JingDe`）下，账号主页天然就是它们的聚合入口。

## 使用说明

- 每个子目录是一个独立的小工具，打开对应目录查看其内部的说明与运行方式。
- 个人 Git 使用笔记见 [`git用法记录/git基础用法.md`](./git用法记录/git基础用法.md)。

## 仓库约定

- 不同语言 / 平台的小工具以**子目录**方式共存，不单独分仓，保持"组织在一起"。
- 构建产物（如 Android 的 `build/`、`*.apk`）、本地配置（`local.properties`）、缓存（`__pycache__/`）、本地项目记忆（`.workbuddy/`）均已在 `.gitignore` 中排除，不会进仓库。
